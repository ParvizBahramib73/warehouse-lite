# انتشار امن پیش‌نمایش 0.2 روی GitHub Pages

این نسخه مستقل از `0.1.8` است و فقط برای آزمایش با **داده ساختگی** است. برای آدرس پیش‌نمایش GitHub Pages از مسیر زیر استفاده کنید:

https://parvizbahramib73.github.io/warehouse-lite/preview/v0.2/

کد و آزمون‌های پیش‌نمایش در مسیر `preview/v0.2/` مخزن `ParvizBahramib73/warehouse-lite` هستند. Workflows ریشه ابتدا نسخه اصلی را بدون تغییر می‌سازند و بعد خروجی پیش‌نمایش را فقط به مسیر `dist/preview/v0.2/` اضافه می‌کنند. مسیر ریشه و پایگاه داده نسخه اصلی دست‌نخورده‌اند.

کنترل‌های پس از انتشار: بازشدن صفحه، بارگیری فایل‌های CSS/JS/Manifest بدون خطای 404، نصب آفلاین در Chrome Android، خرید و فروش با کالای ساختگی، سربرگ/چاپ فاکتور، قیمت جایگزینی، هشدار انقضا و چک، خروجی پشتیبان رمزدار و Restore در پروفایل مرورگر آزمایشی دوم. تا اجرای این موارد و طراحی مهاجرت امن، از داده واقعی و پشتیبان نسخه قبلی استفاده نکنید.

اگر workflow شکست خورد، `master` نسخه اصلی را دوباره منتشر می‌کند؛ خروجی انتشار جدید جایگزین نسخه قبلی نشده است. از داده واقعی برای تست استفاده نکنید.
