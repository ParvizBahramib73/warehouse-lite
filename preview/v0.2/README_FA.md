# انبار من | پیش‌نمایش مستقل نسخه 0.2.0

این پوشه بسته نسخه پیش‌نمایش اصلاحات علی را نگهداری می‌کند. فایل `site.tar.xz` حاوی کد HTML، CSS و JavaScript نسخه پیش‌نمایش است و در GitHub Actions فقط در مسیر `dist/preview/v0.2/` باز می‌شود.

**آدرس نمایشی پس از موفقیت انتشار:**
https://parvizbahramib73.github.io/warehouse-lite/preview/v0.2/

**برنامه اصلی بدون تغییر:** https://parvizbahramib73.github.io/warehouse-lite/

این نسخه با سورس قدیمی‌تر بازسازی شده و با پایگاه داده، فاکتورها و پشتیبان نسخه 0.1.8 سازگار نشده است. پایگاه داده مجزا (`warehouse-lite-feedback-preview-v02`) و Service Worker با scope همین پوشه استفاده می‌شود؛ پشتیبان برنامه اصلی را در اینجا وارد نکنید. فقط با اطلاعات ساختگی آزمایش شود.

امکانات شامل قیمت جایگزینی و قیمت پیشنهادی با حاشیه پیش‌فرض ۱۰٪، ارزش‌گذاری سه‌گانه موجودی، دوره‌های تاریخ انقضا، چک پرداختی، سررسید فاکتور، واحدهای اضافی، چاپ A5/A4، تم تاریک و فیلتر جست‌وجوی محصول است.

**محدودیت‌ها:** OCR/AI یکپارچه، مهاجرت اطلاعات واقعی و شخصی‌سازی کامل هنوز اجرا نشده؛ آزمایش Android واقعی و بازیابی روی دستگاه دوم انجام نشده است. ۱۵ تست خودکار پیش‌نمایش روی محیط محلی قبلاً موفق بودند، ولی این بسته تنها فایل‌های اجرایی را شامل می‌شود. موفقیت CI لزوماً به معنای تأیید حسابداری یا استفاده عملیاتی نیست.
